# Hướng dẫn Github và VScode

Hướng dẫn dùng Github và Visual Studio Code (VScode) portable gọn nhẹ dành cho người mới

Bản portable nghĩa là bản chạy sẵn, không cần cài đặt gì

Trong số các phần mềm viết code thì vscode hỗ trợ mạnh nhất, có thể cài thêm nhiều tiện ích, và còn miễn phí

Hỗ trợ tích hợp nhiều tác nhân AI như Copilot, Antigravity, Claude,...
